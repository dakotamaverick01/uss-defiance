# Deck 2 part 2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the first officer's quarters, two senior officers' cabins, a side passage and an observation lounge with an exterior set piece on Deck 2, then re-bake and ship the stage.

**Architecture:** All geometry goes in js/deck2.js (loaded before bake.js) using the existing d2room/d2wall/doorAt helpers. The set piece is a group EXTSET inside DECK2 that uses MeshMatcapMaterial and additive glow, so the bake skips it. Stations and panels go in lift.js beside the other Deck 2 stations. Screen kinds go in screens.js.

**Tech Stack:** three.js 0.186 (global scripts), headless Chromium via Playwright for checks, Blender bpy 5.0.1 for the bake.

**Spec:** docs/superpowers/specs/2026-11-26-deck2-part2-design.md

## Global Constraints
- Strictly original: no copied rooms, furniture or silhouettes.
- Seating only through makeChair(..., 'dining' | 'station').
- Every desk with a display uses deskSurface().
- Partition walls at least 10 cm from any other wall. Rooms built with d2room (6 cm inset).
- Nothing personal in files. Commits as dakotamaverick01 <dakotamaverick01@users.noreply.github.com>.
- One re-bake after all geometry: bake_export.py, then bake_blender.py <work> 160 with RIG='{"panel": 6.0, "disc": 6.0, "spot_bridge": 220.0, "spot_room": 150.0, "down": 0.9}', then bake_encode.py, then set "exposure": 10.5 in bake/bake.json (1-space indent).

## Review Focus
1. Walking from the lobby to every new room without snagging on the 12 cm gap between back-to-back walls at each doorway or opening. Test: a scripted walk with collide() through each doorway.
2. A phone opening the lounge: the set piece must not drop the frame rate. Check renderer.info triangle count, and keep the set under ~20k triangles.
3. Red alert in the lounge: the shutters close over the whole window and the set piece doesn't show through gaps.
4. Reading the directory screen and panel once nothing is sealed: no empty "Still sealed" row.
5. Riding the lift back to Deck 1: none of the new Deck 2 geometry or screens leaks onto the bridge (DECK2 hidden, the set piece inside DECK2).
